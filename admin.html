Entrar al panel

Esta página guarda tus cambios en tu repositorio de GitHub. Solo necesitas entrar una vez en cada navegador.

¿Cómo consigo el token?
  1. En GitHub abre Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elige "Only select repositories" y marca solo el repositorio de tu tienda.
  3. En Permissions → Repository permissions pon Contents: Read and write y Actions: Read and write.
  4. Pulsa "Generate token", copia el texto que empieza con github_pat_ y pégalo arriba.
