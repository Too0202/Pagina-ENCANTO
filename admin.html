Entrar al panel

La primera vez entras con tu token de GitHub. Luego creas tu usuario y contraseña y ya no lo necesitas.

¿Cómo consigo el token?
  1. Abre github.com/settings/personal-access-tokens/new.
  2. En Repository access elige "Only select repositories" y marca solo el repositorio de tu tienda.
  3. En Repository permissions pon Contents: Read and write y Actions: Read and write.
  4. Pulsa "Generate token", copia el texto que empieza con github_pat_ y pégalo arriba.

Con esto entras al panel desde cualquier equipo sin pegar el token.

Cómo funciona y qué cuidar

Tu token de GitHub se guarda cifrado con tu contraseña en el archivo admin-vault.json de tu repositorio. Sin la contraseña nadie puede abrirlo. Como el repositorio es público, la contraseña tiene que ser larga y que nadie más use: si es fácil de adivinar, alguien podría descifrarlo.

Si olvidas la contraseña, entra con un token nuevo y crea otra. Si el token vence, haz lo mismo.
